# Customer-Churn-Prediction-Using-Python
A Data Science Capstone Project using Python to analyse customer churn, perform data visualisation, and build Logistic Regression and K-Means models using the Telco Customer Churn dataset.
# Customer Churn Prediction and Analysis Using Python

## Project Overview
This project focuses on analysing customer churn using Python and Machine Learning. It uses the Telco Customer Churn dataset to understand customer behaviour and predict whether a customer is likely to leave a telecommunications company.

## Objectives
- Analyse customer churn patterns.
- Clean and preprocess customer data.
- Perform Exploratory Data Analysis (EDA).
- Build a customer churn prediction model.
- Apply customer segmentation using clustering.
- Provide business insights and recommendations.

## Dataset
- **Dataset Name:** Telco Customer Churn
- **Source:** Kaggle
- **Total Records:** 7,043
- **Total Columns:** 33
- **Target Variable:** Churn Label

[Kaggle Dataset Link](https://www.kaggle.com/datasets/yeanzc/telco-customer-churn-ibm-dataset)

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
1. **Logistic Regression** – Used for customer churn prediction.
2. **K-Means Clustering** – Used for customer segmentation.

## Model Results

| Evaluation Metric | Result |
|---|---:|
| Accuracy | 79.70% |
| Precision | 63.75% |
| Recall | 54.55% |
| F1-Score | 58.79% |
| ROC-AUC | 0.84 |
| K-Means Silhouette Score | 0.2666 |
